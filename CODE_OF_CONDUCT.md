# Code of conduct

We welcome contributors with different backgrounds and experience levels. Treat one another with respect, discuss technical disagreements with evidence, and help newcomers understand project expectations.

Harassment, discriminatory language, personal attacks, threats, disclosure of private information and deliberate credential exposure are not acceptable. Do not pressure contributors to share browser sessions, passwords, private account data or unredacted logs.

These expectations apply to project issues, pull requests and other project-maintained spaces. Maintainers may edit or remove inappropriate material, close disruptive discussions, or restrict participation when necessary. They should explain decisions where doing so does not disclose private information or worsen harm.

For a concern, contact the maintainer through an available private channel listed on [their GitHub profile](https://github.com/takiAA). If none is available, ask for a private channel without posting identifying details or allegations publicly. Security vulnerabilities follow [SECURITY.md](SECURITY.md).

Good-faith reporting must not result in retaliation. This is a project-specific conduct policy, not a promise that maintainers can resolve disputes outside project spaces.
